# Story 3.6: Bootable System Integration Testing and Demo Preparation

**Status:** Draft

## Story

**As a** SecureWipe team preparing for hackathon demonstration,  
**I want** comprehensive integration testing and demo preparation for the bootable system,  
**so that** we have reliable fallback strategies and can deliver a successful demonstration regardless of hardware issues.

## Acceptance Criteria

1. **VM Testing Environment** - Complete UEFI/Secure Boot testing in QEMU/VirtualBox with saved snapshots
2. **Hardware Compatibility Matrix** - Validated device detection on Intel/AMD platforms with different storage types
3. **Demo Fallback Strategies** - Pre-recorded sequences and backup demos for time-constrained presentations
4. **Performance Optimization** - ISO size under 1.5GB with 5-10 minute wipe cycles on test devices
5. **Certificate Integration Testing** - End-to-end validation of certificate generation and offline verification
6. **GUI Resilience Testing** - Automatic fallback to TUI when GUI components fail
7. **Professional Demo Assets** - Polished interface, boot splash, and presentation materials
8. **Cross-Team Compatibility** - Certificate schema compatibility between desktop and bootable modes

## Tasks / Subtasks

- [ ] **VM Testing Infrastructure Setup** (AC: 1)
  - [ ] Configure QEMU with UEFI firmware and Secure Boot enabled
  - [ ] Create test disk images (8GB, 32GB, 1TB) for wipe testing
  - [ ] Setup VirtualBox environment with USB passthrough for real device testing
  - [ ] Create VM snapshots at key demo points for instant recovery

- [ ] **Hardware Compatibility Validation** (AC: 2)
  - [ ] Test nwipe device detection on various storage types (SSD, HDD, USB)
  - [ ] Validate hardware information collection across Intel/AMD platforms (minimum 3 platforms each)
  - [ ] Test encrypted drive detection and limitation warnings
  - [ ] Document hardware-specific quirks and workarounds

- [ ] **Demo Preparation and Fallback Systems** (AC: 3, 7)
  - [ ] Create 5-minute live demo sequence with 8GB USB drive
    - [ ] Minutes 1-2: Boot and GUI demonstration
    - [ ] Minutes 3-4: Device selection and confirmation process
    - [ ] Minute 5: Certificate generation and verification
  - [ ] Record backup demo video showing complete wipe process
  - [ ] Prepare presentation slides with screenshots and key features
  - [ ] Create demo script with timing and fallback decision points

- [ ] **Performance Testing and Optimization** (AC: 4)
  - [ ] Benchmark wipe speeds on different device types and sizes
  - [ ] Optimize ISO size through package removal and compression
  - [ ] Test boot time and application startup performance (target: < 30 seconds)
  - [ ] Validate GUI launch time (target: < 10 seconds after boot)
  - [ ] Test device detection speed (target: < 5 seconds for standard configurations)
  - [ ] Validate memory usage during large device operations

- [ ] **Certificate Integration Testing** (AC: 5, 8)
  - [ ] Test certificate generation with both pyca/cryptography and minisign
  - [ ] Validate certificate schema compatibility with desktop application
  - [ ] Test QR code generation and scanning with mobile devices
  - [ ] Verify offline certificate verification with standalone verifier

- [ ] **GUI Resilience and Fallback Testing** (AC: 6)
  - [ ] Test GUI failure scenarios and automatic TUI fallback
  - [ ] Validate TUI interface functionality and navigation
  - [ ] Test touch-friendly interface on tablet hardware
  - [ ] Verify accessibility features and high contrast mode

- [ ] **Professional Polish and Integration** (AC: 7)
  - [ ] Implement custom Plymouth boot splash with SecureWipe branding
  - [ ] Polish GUI with professional styling and animations
  - [ ] Test auto-launch functionality and fullscreen presentation
  - [ ] Create user documentation and quick reference cards

### Technical Implementation Context

**VM Testing Setup:** [Source: epic-3-bootable-deep-clean-system.md#testing-validation-framework]
```bash
# UEFI test environment configuration
qemu-system-x86_64 \
  -enable-kvm -m 4G \
  -drive if=pflash,format=raw,readonly,file=/usr/share/ovmf/OVMF_CODE_4M.fd \
  -drive if=pflash,format=raw,file=test_OVMF_VARS.fd \
  -cdrom securewipe-deep-clean.iso \
  -drive file=test-disk.img,format=raw,if=virtio
```

**ISO Optimization:** [Source: epic-3-bootable-deep-clean-system.md#step-by-step-iso-customization-process]
- Remove unnecessary packages: libreoffice*, thunderbird, firefox
