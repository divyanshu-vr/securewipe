# Story 1.2: Desktop Application Foundation

## Status
Done

## Story
**As a** desktop application user,  
**I want** a basic desktop application that launches successfully on Windows,  
**so that** I can begin the file scanning process with confidence.

## Acceptance Criteria
1. Python desktop application launches without errors on Windows 10/11
2. UI framework choice finalized by day 2 (tkinter for no external dependencies)
3. Basic UI displays main window with SecureWipe branding and clear navigation
4. Application detects current user directories (Documents, Downloads, Desktop, temp folders)
5. Application gracefully handles missing directories or permission issues with clear messaging
6. Basic logging framework integrated for debugging and audit trail
7. Linux compatibility as stretch goal, not blocking requirement

### Technical Constraints
**UI Framework Requirements** [Source: architecture/tech-stack.md#desktop-framework]:

- Cross-platform compatibility (Windows primary, Linux stretch)

**Logging Standards** [Source: architecture/coding-standards.md#owasp-logging]:
- Use shared.logging.secure_logger for ALL operations
- Never log full file paths - use sanitizer.sanitize_path()
- Log levels: ERROR for failures, INFO for operations, DEBUG for development

**Error Handling Pattern** [Source: architecture/coding-standards.md#error-handling]:
```python
try:
    result = directory_operation()
except PermissionError as e:
    logger.error(f"Permission denied: {sanitizer.sanitize_path(path)}")
    raise SecureWipeError("Insufficient permissions") from e
```
