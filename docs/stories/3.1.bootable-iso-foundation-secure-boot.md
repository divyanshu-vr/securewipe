# Story 3.1: Bootable ISO Foundation with Secure Boot Compatibility

## Status
Draft

## Story
**As a** user preparing to completely wipe a device for disposal,  
**I want** a bootable ISO that starts reliably with Secure Boot enabled,  
**so that** I can perform complete system wiping on modern hardware without BIOS modifications.

## Acceptance Criteria
1. Ubuntu LTS live ISO base with Microsoft-signed shim for Secure Boot compatibility
2. Minimal customization approach - add SecureWipe app and dependencies only
3. ISO boots successfully in UEFI VM with OVMF/EDK2 firmware
4. VM snapshot saved as guaranteed demo fallback
5. Tested on Intel iGPU and AMD/NVMe platforms by day 3
6. Fallback BIOS compatibility maintained for older hardware
7. ISO size under 2GB for standard USB drive compatibility

### Technical Constraints
**Secure Boot Requirements** [Source: architecture/tech-stack.md#bootable-base]:
- Preserve Microsoft-signed shim for UEFI compatibility
- Maintain certificate chain for trusted boot
- No custom kernel modifications that break Secure Boot
- Standard Ubuntu boot process with minimal changes

**ISO Size Constraints**:
- Maximum 2GB for standard USB drive compatibility
- Remove unnecessary Ubuntu packages and locales
- Optimize Python dependencies and SecureWipe application
- Compress ISO efficiently while maintaining boot compatibility

**Hardware Compatibility** [Source: architecture/tech-stack.md#bootable-base]:
- UEFI firmware support (OVMF/EDK2 for testing)
- Legacy BIOS fallback for older hardware
- Intel iGPU and AMD discrete graphics support
- NVMe and traditional storage compatibility
