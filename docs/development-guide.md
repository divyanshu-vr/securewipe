# SecureWipe Development Guide

## Quick Start

### Prerequisites
- Python 3.8+ 
- Git
- Virtual environment support

### Setup
```bash
# Clone repository
git clone <repository-url>
cd SecureWipe

# Setup development environment
./scripts/setup-dev-env.sh    # Linux/Mac
# OR
scripts\setup-dev-env.bat     # Windows

# Activate virtual environment
source venv/bin/activate      # Linux/Mac
# OR
venv\Scripts\activate.bat     # Windows
```

## Team Structure

### Team 1: Desktop Application
**Location:** `desktop-app/`
**Focus:** Quick Clean mode for user directories

### Team 2: Bootable ISO  
**Location:** `bootable-iso/`
**Focus:** Deep Clean mode for complete system wiping

### Shared Components
**Location:** `shared/`
**Focus:** Certificate schema, cryptography, logging

## Development Workflow

### Running Tests
```bash
# All tests
pytest

cd desktop-app && pytest tests/
```


## Shared Module Usage

### Import Pattern
```python
import sys
from pathlib import Path
sys.path.append(str(Path(__file__).parent.parent / "shared"))

from schema.validator import validate_certificate
from crypto.key_management import get_signer
```

### Certificate Generation
```python
from shared.crypto.key_management import get_signer, generate_and_store_keypair
from shared.schema.validator import validate_certificate

# Generate keys
public_key, private_key_path = generate_and_store_keypair()

# Sign certificate
signer = get_signer()
signature = signer.sign_certificate(cert_data, private_key)

# Validate
validate_certificate(certificate)
```

## Architecture Guidelines

### Certificate Schema
- All certificates MUST validate against `shared/schema/certificate_v1.json`
- Use `shared.schema.validator.validate_certificate()` before saving
- Schema supports additive-only changes for compatibility

### Cryptography
- Primary: pyca/cryptography (RSA-2048-SHA256)
- Fallback: minisign (Ed25519)
- Self-signed certificates for MVP

### Logging
- Use OWASP-compliant logging patterns
- Sanitize file paths before logging
- Never log sensitive data

### Cross-Platform
- Use `pathlib.Path` for all file operations
- Test on both Windows and Linux
- Handle platform-specific secure deletion tools

## Testing Strategy

### Unit Tests
- Test individual components in isolation
- Mock external dependencies
- Achieve >90% code coverage

### Integration Tests  
- Test certificate compatibility between desktop/bootable modes
- Validate cryptographic operations end-to-end
- Test cross-platform functionality

### Compatibility Tests
- Ensure certificates generated by desktop app validate in bootable mode
- Test schema migration scenarios
- Validate fallback cryptography implementations

## Troubleshooting

### Common Issues
1. **Import errors:** Ensure shared module is in Python path
2. **Cryptography failures:** Check if pyca/cryptography is installed, fallback to minisign
3. **Schema validation errors:** Verify certificate structure matches schema
4. **Permission errors:** Ensure proper file permissions for key storage

### Debug Mode
```bash
export SECUREWIPE_DEBUG=true
export SECUREWIPE_LOG_LEVEL=DEBUG
```
